## Commit a4cce7a — Workspace directory infrastructure for watcher

**Branch:** `refactor/workspace-mounts`

**What changed:**

- Added `WORKSPACES_ROOT` env var (defaults to `/app/workspaces` in Docker); documented in `.env.example`
- Added `workspace_path` column to the `watched_directories` DB table
- `create_watched_directory()` now auto-generates a workspace path as `{WORKSPACES_ROOT}/{username}/{slug}` and creates it on disk immediately
- `_watcher_execute()` now copies incoming files into `{workspace_path}/incoming/` instead of operating directly on the watched folder — watched folders can now be **read-only** (e.g., Docker bind mounts, network shares)
- Cross-workspace detection: watcher snapshots sibling workspaces and cascades AI tasks when files land in another workspace as a result of a task
- `update_watched_directory()` / `delete_watched_directory()` updated to handle `workspace_path`; deletion cleans up the workspace dir on disk
- `watcher_service.py`: switched `Observer` → `PollingObserver` for compatibility with non-inotify filesystems (Docker volumes, NFS)
- `Workspaces.jsx`: displays `ws.workspace_path` instead of `ws.path`

**Why it matters:** Decouples the watched folder (source, potentially read-only) from the workspace (destination, always writable). Any directory — including read-only Docker mounts — can now be a watch target.

## Commit 09f8484 — Refactor file imports to target workspace directory

**Branch:** `refactor/workspace-mounts`

**What changed:**

- `import_files_to_workspace()` in `backend.py`: upload target changed from `wd["path"]` (watched dir) to `{workspace_path}/incoming/`
- Removed the `.write_test` writability check — no longer needed since the workspace directory is always writable
- After a successful upload, `_watcher_execute()` is called immediately with `saved_paths` — uploaded files are automatically processed by the AI agent without a separate trigger
- API response now returns `incoming_dir` as `target_path`

**Why it matters:** Completes the architecture from a4cce7a. Uploading a file now immediately kicks off the agent pipeline. The watched folder is never touched during upload.
