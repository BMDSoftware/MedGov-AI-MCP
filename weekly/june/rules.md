# JBI Submission Rules

## Structure
- Sections: Introduction / Related Work / Methods / Results / Discussion / Conclusion
- Statement of Significance table at end of Introduction (<=150 words): Problem | What is Already Known | What this Paper Adds | Who Benefits
- Conclusion must state applicability of the research

## Limits
- Body: <=6000 words
- Figures + tables combined: <=8
- Abstract: <=300 words, structured as Objective / Methods / Results / Conclusion

## Keywords
- 1 to 7 keywords, prefer single words, no "and" or "of"

## Required extras
- CRediT author contributions statement in Acknowledgements
- Declaration of generative AI use (new section before references)
- Data statement: deposit code/data in a repository (GitHub accepted), cite it

## Scope
- Imaging papers are only in scope if they combine knowledge-intensive approaches involving ontologies
- Must explicitly frame ontology use (for example RadLex) in abstract and introduction

## References
- Numbered square bracket style: [1], [2], ...

## Template
- Elsevier LaTeX template encouraged; double-column is permitted for LaTeX
