Local specs: Ryzen 5 8645HS (6 cores / 12 threads, Zen 4), NVIDIA RTX 3050 6GB

- Server is a VM with only 4 vCPUs - not the full 16-core/32-thread Ryzen 9 5950X
- Cellpose (unrestricted): can only use 4 vCPUs on server vs 12 threads locally + VM overhead. Explains ~3h vs 12m37s gap.
- MONAI (OMP_NUM_THREADS=1): 1 thread is 1 thread regardless of VM or not. Times are similar across machines.
- Server has a better GPU (RTX 3060 vs RTX 3050 6GB) - GPU inference would likely be faster on server if tested
- Cellpose CPU gap is a VM configuration issue, not a hardware limitation - allocating more vCPUs would dramatically improve it
- Zen 4 (local) vs Zen 3 (server) also contributes - newer AVX instructions and better cache behavior matter for SAM/ViT models
