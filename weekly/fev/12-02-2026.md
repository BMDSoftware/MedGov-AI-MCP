File Upload Flow (new)

1. User uploads CT_scan.dcm via /api/upload
2. Backend copies to data/uploads/{uuid}_{original_name}
3. DB entry: uploaded_files(session_id, "CT_scan.dcm", "data/uploads/abc123_CT_scan.dcm", "dcm", 1234567)
4. On /api/process-query, file path comes from DB (not temp files)
5. File survives restart - next session can reference it

Session Persistence Flow (new)

1. Backend starts → creates new session (unsaved, auto-name "Session 2026-02-12 21:00")
2. User works: uploads files, runs tools → context accumulates in memory + DB
3. User clicks "Save Session" → POST /api/save-session {name: "CT Analysis Feb 12"}
4. Session marked persisted=1 in DB
5. Backend restarts → new empty session
6. User clicks "Load Session" → GET /api/sessions shows saved sessions
7. POST /api/load-session {session_id} → restores context + file references
