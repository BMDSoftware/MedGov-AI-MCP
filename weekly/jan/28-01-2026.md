The advantages of using MCP as it is:
1. Decoupled - Each server is independent. MONAI doesn't know about RadLex. They can be developed, tested, deployed separately.
2. Discoverable - Add a new MCP server to the config, restart, and the orchestrator automatically knows about all its tools.
3. Standardized - Any MCP-compatible client (Claude Desktop, your app, someone else's app) can connect to your MONAI server.
4. Language agnostic - Your servers are Python, but they could be Node.js, Rust, anything.
5. Swappable - Replace your MONAI server with a better one, nothing else changes.

  To be fair the orchestrator isn't doing much at the moment


    When you click "Analyze Image":

1. Backend receives request
2. Creates temp file
3. Calls execute_task()
4. Code checks: is analyze_done? No → call analyze_image
5. Code checks: is list_done? No → call list_models
6. Code checks: is model_downloaded? Yes → skip download
7. Code checks: is inference_done? No → call run_inference
8. Code checks: is inference_done? Yes → return results

When you click "Generate Report":

1. Backend receives request
2. Directly calls radlex.list_templates
3. Directly calls radlex.generate_report
4. Returns report

The LLM (deepseek-r1) is never consulted in either flow. The orchestrator is just a series of if/else statements.

What the orchestrator SHOULD be doing:

1. User: "Analyze this CT of the chest"
2. LLM receives: tool descriptions + user message
3. LLM thinks: "I need to analyze the image first"
4. LLM calls: analyze_image → gets result
5. LLM thinks: "It's CT chest, let me find lung models"
6. LLM calls: list_models(modality="CT", body_part="chest")
7. LLM thinks: "lung_nodule model exists but not downloaded"
8. LLM calls: download_model("lung_nodule_ct_detection")
9. LLM calls: run_inference
10. LLM thinks: "Found nodules, I should generate a report"
11. LLM calls: radlex.generate_report
12. LLM: "Here's your report with findings"
                     
The difference: In the current code, the code decides. In a real agentic system, the LLM decides based on context, results, and user intent.
