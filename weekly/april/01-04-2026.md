## Architecture


Right now:

- The agent decides whether to call queue_task or call a tool directly based on the system prompt rules
- The task_runner handles known types (inference, cellpose, report) with dedicated handlers


I wanted that:
any tool call that produces results or runs an external model should automatically run in the background, without the agent having to explicitly choose queue_task. The agent just calls the tool normally, and the system intercepts it.
