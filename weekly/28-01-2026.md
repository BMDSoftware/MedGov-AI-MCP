The advantages of using MCP as it is:
1. Decoupled - Each server is independent. MONAI doesn't know about RadLex. They can be developed, tested, deployed separately.
2. Discoverable - Add a new MCP server to the config, restart, and the orchestrator automatically knows about all its tools.
3. Standardized - Any MCP-compatible client (Claude Desktop, your app, someone else's app) can connect to your MONAI server.
4. Language agnostic - Your servers are Python, but they could be Node.js, Rust, anything.
5. Swappable - Replace your MONAI server with a better one, nothing else changes.
